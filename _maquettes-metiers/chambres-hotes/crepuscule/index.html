Passez la souris : la lampe vous suit

Quand le jour tombe, la maison s'allume.

Maison d'hôtes de quatre chambres. Petit-déjeuner maison compris dans chaque nuitée, table d'hôtes trois soirs par semaine.

Les chambres

Nous avons trouvé cette maison un soir de novembre, toutes fenêtres éteintes.

Il nous a fallu trois hivers pour rallumer chaque pièce : les murs de pierre, les tomettes, la grande cuisine où tout le monde finit par s'asseoir. Aujourd'hui nous ouvrons quatre chambres, pas une de plus, pour avoir le temps de vous recevoir.

Le matin, nous servons nous-mêmes le petit-déjeuner. Le soir, trois fois par semaine, nous dînons avec vous. Entre les deux, la maison est à vous.
